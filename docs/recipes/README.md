# Рецепты

Рецепт — порядок добавления возможности, которой в шаблоне нет: когда она нужна, что добавить, на что посмотреть в проектах-образцах и как проверить результат. Код в рецепты не копируется: он берётся из образца и правится под проект.

Пути образцов записаны как `<проект>/<путь от корня проекта>`: `ai-memory/…`, `songframe/…`, `forktopus/…`. Образцы — проекты того же владельца на том же стеке (Go, Wails 3, React, MUI); их репозитории: [ai-memory](https://github.com/yarkovaleksei/ai-memory), [songframe](https://github.com/ai-animation-tools/songframe), [forktopus](https://github.com/forktopus/forktopus). Пакеты go-desktop-kit названы ссылками на версию `v0.1.1`, которую подключает шаблон.

| Рецепт | Когда нужен |
| --- | --- |
| [Второй бинарник в cmd/](second-binary.md) | Рядом с окном нужна консольная программа: CLI, MCP-сервер, помощник |
| [Внешние программы](external-programs.md) | Приложение запускает git, ffmpeg и другие программы системы |
| [SQLite без CGO](sqlite.md) | Нужна локальная база или индекс |
| [Корзина ОС](os-trash.md) | Удаление файлов пользователя должно быть обратимым |
| [react-admin](react-admin.md) | Интерфейс — таблицы, формы и списки записей |
| [Storybook](storybook.md) | Компоненты нужно смотреть и проверять отдельно от приложения |
| [Подпись кода и нотаризация](code-signing.md) | Пакеты должны открываться без предупреждений системы |
| [Третий язык интерфейса](third-language.md) | Кроме русского и английского нужен ещё язык |
| [Как убрать ненужную возможность](remove-feature.md) | Проекту не нужны трей, автозапуск или AppImage |

Каждый рецепт кончается проверкой; после любого из них — `wails3 task check`. Новая зависимость записывается решением с причиной (см. [code-style.md](../code-style.md#общее)).
