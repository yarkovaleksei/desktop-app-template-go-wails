# Корзина ОС

## Когда нужно

Приложение удаляет файлы пользователя, и ошибку нужно уметь исправить: удалённое должно оказаться в корзине системы, а не исчезнуть.

## Что добавить

- Пакет ядра (`internal/<пакет>`, например trash) с функцией `Move(path)` и файлами по ОС: `trash_linux.go` — корзина freedesktop (файл в `files/`, описание в `info/<имя>.trashinfo`, корзина своего тома или домашняя), `trash_windows.go` — корзина Windows через системный вызов, остальные ОС — ошибка «не поддерживается», данные при этом не трогаются.
- На macOS, пока своей реализации нет, удаление в корзину недоступно: кнопка выключена с пояснением, а не удаляет безвозвратно.
- Код ошибки (`trash.unsupported`, `trash.failed`) и тексты в обоих словарях.

## На что смотреть в образцах

- `songframe/internal/trash/trash.go` — общий интерфейс и ошибка «не поддерживается».
- `songframe/internal/trash/trash_linux.go` — корзина freedesktop, в том числе на другом томе.
- `songframe/internal/trash/trash_windows.go` — корзина Windows.

## Как проверить

- Тесты Linux на временном `XDG_DATA_HOME`: файл ушёл в `files/`, `.trashinfo` с исходным путём и датой, повтор имени не затирает прежний файл.
- Вручную: удалённый из приложения файл виден в корзине системы и восстанавливается её средствами. На ОС без поддержки — кнопка выключена, файл на месте.
