# SQLite без CGO

## Когда нужно

Приложению нужна локальная база: индекс для поиска, история, кэш с запросами. Для настроек и небольших файлов состояния база не нужна — их хранит [settings](https://github.com/yarkovaleksei/go-desktop-kit/tree/v0.1.1/settings) или [atomicfile](https://github.com/yarkovaleksei/go-desktop-kit/tree/v0.1.1/atomicfile) из kit.

## Что добавить

- Драйвер на чистом Go — `modernc.org/sqlite`: сборка остаётся без новых системных библиотек и одинаковой на трёх ОС. Решение о зависимости записывается с причиной.
- Пакет ядра в `internal/` (`internal/<пакет>`, например store): открытие базы, схема, запросы; Wails не импортирует.
- Файл базы — в каталоге данных (`Dirs.Data` из [appdirs](https://github.com/yarkovaleksei/go-desktop-kit/tree/v0.1.1/appdirs)), а не в кэше, если данные нельзя восстановить; кэш-индекс, который пересоздаётся, — в `Dirs.Cache`.
- Версия схемы в таблице базы и переходы между версиями при открытии; если база — кэш, вместо перехода её можно пересоздать.
- Режим WAL и одно подключение на запись; закрытие базы при выходе (`OnShutdown`).

## На что смотреть в образцах

- `ai-memory/internal/index/index.go` — подключение драйвера, версия схемы в таблице `meta`, пересоздание индекса при смене версии.
- `ai-memory/go.mod` — версия драйвера.

## Как проверить

- Тесты пакета на базе во временном каталоге (`t.TempDir()`): создание, переход со старой версии схемы, повторное открытие.
- `wails3 task build` на трёх ОС без CGO-зависимостей кроме Wails (CI `check`); `wails3 task check:race`.
