# Внешние программы

## Когда нужно

Приложение запускает программы системы: git, ffmpeg, архиваторы, редакторы. Открыть файл, папку или адрес программой по умолчанию — не этот рецепт: это уже делает пакет kit [opener](https://github.com/yarkovaleksei/go-desktop-kit/tree/v0.1.1/opener) (так работает «Открыть папку журнала»).

## Что добавить

- Пакет ядра в `internal/` (`internal/<пакет>`, например для ffmpeg), который запускает программу через [procrun](https://github.com/yarkovaleksei/go-desktop-kit/tree/v0.1.1/procrun) из kit: без shell, с отменой через `context.Context`, таймаутом, ограниченным захватом вывода и завершением всего дерева процессов. Ненулевой код выхода — в `Result.Code`, а не ошибка запуска.
- Запуск принимает `procrun.Runner`, а не вызывает `exec` напрямую: тест подставляет поддельный запуск. Журнал команд — `procrun.Logged` с функцией маскировки секретов.
- Поиск программы (`exec.LookPath`) и проверка версии (`<программа> --version`) при первом обращении; если программы нет — ошибка с кодом (`media.ffmpeg-missing`) и текстом в обоих словарях, объясняющим, что поставить.
- В AppImage окружение образа (`LD_LIBRARY_PATH` и другие) не должно попадать в дочерние программы системы: при запуске из AppImage его нужно очищать.

## На что смотреть в образцах

- `forktopus/internal/runner/runner.go` — интерфейс запуска и реализация с подменой в тестах (`forktopus/internal/runner/runner_test.go`).
- `forktopus/internal/tools/tools.go` — проверка наличия программы и её версии.
- `forktopus/internal/launch/launch.go` — поиск программ и очистка окружения AppImage для дочерних процессов.
- `songframe/internal/derivedworkflow/workflow.go` — поиск ffmpeg и ffprobe.
- `ai-memory/internal/backup/backup.go` — git с `context.Context`.

## Как проверить

- Тесты пакета с поддельным `Runner`: успех, ненулевой код, нет программы, отмена.
- Вживую: программа есть — результат на экране; программы нет — понятная ошибка на обоих языках; отмена долгой операции завершает и дочерние процессы (`ps` после отмены).
- `wails3 task check:race`, если запуск идёт из горутин.
