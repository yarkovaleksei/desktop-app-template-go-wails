# Документация

Карта документов репозитория: какой документ чем владеет и когда его обновлять. У каждого сведения один владелец; остальные документы на него ссылаются, а не повторяют.

Правило «документация и код»: сведения о продукте и правилах — в документах; наблюдаемое поведение — в тестах; устройство — в коде и комментариях. Изменение поведения описывается в документе-владельце в том же коммите; какой документ владеет областью кода — в [карте кода](code-map.md).

| Документ | Чем владеет | Когда обновлять |
| --- | --- | --- |
| [README.md](../README.md) | Что это, требования, быстрый старт, команды, структура, установка пакетов, как начать проект из шаблона | Новая или удалённая задача Taskfile, новый формат поставки, изменились требования к окружению |
| [README.en.md](../README.en.md) | Перевод `README.md` | В том же коммите, что `README.md`: меняешь один — приведи в соответствие второй. Одинаковый набор разделов и имена пакетов проверяет `internal/archtest` |
| `AGENTS.md` | Правила работы агента в репозитории | Изменился порядок работы, команды проверки, список скиллов |
| `spec/AGENTS.md` | Правила ведения папки `spec/`: план, решения, журнал | Изменилось устройство папки `spec/` |
| [docs/README.md](README.md) | Эта карта | Добавлен, удалён или переименован документ |
| [docs/development.md](development.md) | Устройство: порядок запуска, сервисы, контракт Go ↔ TS, ошибки, события, каталоги, настройки, журнал, тесты, как добавить метод, событие, настройку, страницу | Новый сервис или метод, событие, настройка, каталог, переменная окружения, вид тестов |
| [docs/desktop.md](desktop.md) | Один экземпляр, состояние окна, трей и работа в фоне, автозапуск, уведомления, фоновая проверка обновлений; где что недоступно и что проверено | Изменилось поведение возможности рабочего стола или проверено на новой ОС |
| [docs/code-style.md](code-style.md) | Правила кода Go и TypeScript, проверки перед коммитом | Новое правило или новая проверка правила |
| [docs/ui.md](ui.md) | Правила интерфейса: компоненты, тексты, тема, поведение, окно и проверка | Новое правило интерфейса или новая проверка правила |
| [docs/packaging.md](packaging.md) | Форматы поставки, сборка, метки формата, AppArmor, подпись, иконка, проверка пакета | Новый или удалённый формат, изменился состав пакета, иконка, зависимости пакетов |
| [docs/release.md](release.md) | Порядок выпуска и действия при сбое | Изменились задачи `release:*` или workflow `release` |
| [docs/ci.md](ci.md) | Workflows: триггеры, фильтры путей, шаги, разбор падений | Изменился любой файл `.github/workflows/` |
| [docs/code-map.md](code-map.md) | Области кода, пакеты, страницы и их документы-владельцы | Не правится вручную: `wails3 task docs:map` после изменения `internal/repodocs/areas.go`, комментария пакета или JSDoc страницы |
| [docs/recipes/](recipes/README.md) | Рецепты возможностей, которых нет в шаблоне | Рецепт выполнен в проекте (его можно убрать) или образец переехал |

Механически документы проверяет `wails3 task check:docs`: ссылки и якоря, пути в обратных кавычках, задачи `wails3 task …` и скрипты `yarn …`, актуальность карты кода. Смысл текста проверяет только обзор.
