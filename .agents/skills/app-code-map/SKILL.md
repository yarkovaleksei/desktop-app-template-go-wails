# Карта кода Desktop App

Работай в корне репозитория. Карта — [docs/code-map.md](../../../docs/code-map.md); она генерируется из таблицы областей `internal/repodocs/areas.go`, комментариев `// Package` и JSDoc компонентов страниц и вручную не правится. Как устроена проверка — комментарий пакета в `internal/repodocs/areas.go`.

## Найти область

1. Открой [docs/code-map.md](../../../docs/code-map.md) и найди раздел, где перечислен файл, пакет или страница, которые собираешься менять.
2. Строка «Документы» раздела — документы-владельцы: прочитай их до правки, обнови после изменения поведения (`app-docs`).
3. Не нашёл файл ни в одной области — значит, он относится к области своего каталога (строка «Ещё») или это новый код: тогда — раздел ниже.

## Новый пакет Go

1. Комментарий пакета `// Package <имя> …` в одном из его файлов (для нескольких файлов — в `doc.go`). Первое предложение — назначение пакета: оно попадёт в карту, поэтому пишется для читателя карты, а не пересказывает код.
2. Путь пакета от корня — в `Packages` подходящей области `internal/repodocs/areas.go`. Подходящей нет — новая область `kitdocs.Area` с названием `Title` и документами-владельцами `Docs`; порядок областей в таблице — порядок разделов карты.
3. `wails3 task docs:map`, затем `wails3 task check:docs`.
4. `docs/code-map.md` коммитится вместе с пакетом.

## Новая страница

1. Папка `frontend/src/pages/<Имя>Page/`, перед `export function <Имя>Page` — комментарий `/** … */`: его первое предложение попадёт в карту.
2. Имя `<Имя>Page` — в `Pages` области «Интерфейс: страницы» в `internal/repodocs/areas.go`.
3. `wails3 task docs:map` и `wails3 task check:docs`.

Остальные шаги новой страницы (маршрут, вкладка, тексты, тесты) — в [docs/development.md](../../../docs/development.md#страница) и скилле `app-ui`.

## Другие изменения карты

| Что изменилось | Что сделать |
| --- | --- |
| Назначение пакета или страницы | Поправить первое предложение комментария, `wails3 task docs:map` |
| Пакет или страница удалены, переименованы | Поправить `Packages` или `Pages` в `areas.go`, `wails3 task docs:map` |
| Новый файл или каталог вне Go-пакетов и страниц, у которого есть документ-владелец | Путь — в `Paths` области |
| Новый документ-владелец области | Путь с якорем — в `Docs` области |

## Если проверка упала

`TestCodeMap` называет пакет или страницу без области, область с несуществующим путём или устаревшую карту. Первые два — правка `areas.go` или комментария; устаревшая карта — `wails3 task docs:map` и коммит `docs/code-map.md`.

## Что сообщить

Какая область затронута и её документы-владельцы; что добавлено в `areas.go`; что карта перегенерирована и `check:docs` зелёный.
