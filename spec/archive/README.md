# Архив

**Читать только по явной просьбе владельца вернуться к завершённой работе** — например, «как было решено в плане 1.1». При обычном старте, составлении плана и разборе бэклога архив не открывается: действующие решения — в [plan/DECISIONS.md](../plan/DECISIONS.md), правила — в [AGENTS.md](../AGENTS.md).

Архивные записи — история, а не инструкция: пути, команды и решения в них могли устареть. Порядок пополнения — раздел «Завершение плана и архив» в [AGENTS.md](../AGENTS.md#завершение-плана-и-архив).
