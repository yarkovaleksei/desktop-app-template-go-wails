## Только для Claude Code

- Сюда — только то, чего у Codex нет. Общее правило, найденное в работе, записывается в `AGENTS.md` или в документ-владелец из `docs/README.md`, а не в автопамять Claude Code: Codex её не видит.
- Скиллы `.agents/skills/` видны Claude Code через симлинки `.claude/skills/<имя>`; новый скилл получает и каталог, и симлинк.
- `.claude/launch.json` — конфигурации для просмотра во встроенном браузере: `ui` — интерфейс на моках (`yarn dev`, то же, что `wails3 task ui`), `site` — сайт `www/` через `python3 -m http.server`. Проверку интерфейса и сайта в браузере делай через них, а не запуском сервера из оболочки.
